# 🐍 湖北经济学院 Python 学习中心

> 面向 HBUE 学子的 Python 学习资源库，以**全国计算机等级考试二级（Python）**为核心，覆盖从零基础到通过考试的全过程。

## ✨ 项目亮点

- 📖 **7 章知识点笔记**：严格对照《Python 二级考试大纲（2022 版）》编写
- 📝 **海量题库**：按章节分类的选择题、编程题，全部附答案解析
- 📄 **3 套模拟试卷**：完全模拟真实考试题型与分值（选择 40 分 + 操作 60 分）
- 🎯 **期末题库**：湖北经济学院期末原题库整理版（判断题 50 + 单选 119 + 填空 52 + 编程 12）
- 💻 **可运行源代码**：7 大章节 + 经典算法 + 期末编程题答案，50+ 个示例程序
- 🎬 **课程资源**：老师课件 PPT、参考电子书 PDF、教学视频清单

## 🗺️ 学习路线

```
环境搭建（1天） → 基础语法（3天） → 基本数据类型（4天）
→ 程序控制结构（5天） → 函数与代码复用（4天） → 组合数据类型（5天）
→ 文件与数据格式化（3天） → 计算生态（3天） → 刷题冲刺（10天+）
```

详细规划见 [学习路线.md](/学习路线.md)

## 🎓 考试须知

- **考试形式**：上机考试，时长 120 分钟，满分 100 分
- **题型分值**：单项选择题 40 分（含公共基础知识 10 分）、操作题 60 分
- **考试环境**：Windows 7 及以上、Python 3.5.3 ~ 3.9.10、IDLE 开发环境

## 🤝 如何参与

欢迎所有 HBUE 同学为这个项目添砖加瓦！

- **提供真题回忆**：考完试后把你的真题回忆整理成 Markdown，PR 到 `题库/真题回忆/`
- **补充笔记**：发现笔记有误或想补充自己的理解，直接提交 PR
- **贡献代码**：有趣的课堂练习、经典算法题解，请放入 `源代码/` 对应目录

贡献流程见 [CONTRIBUTING.md](/CONTRIBUTING.md)
