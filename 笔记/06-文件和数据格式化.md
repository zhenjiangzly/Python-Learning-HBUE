## 6.1 文件的使用（必考）

### 打开文件 open()

```python
f = open("文件名", "打开模式", encoding="utf-8")
```

| 模式 | 含义 |
|------|------|
| `r` | 只读（默认），文件必须存在 |
| `w` | 写入，文件不存在则创建，**存在则清空覆盖** |
| `a` | 追加，文件不存在则创建，在末尾写入 |
| `x` | 创建新文件，已存在则报错 |
| `+` | 增加读写功能 |
| `b` | 二进制模式 |
| `t` | 文本模式（默认） |

> ⚠️ **必考点**：
> - `w` 模式会**清空原内容**，`a` 模式**不清空**
> - 读取中文必须指定 `encoding="utf-8"`（Windows 上可能出现编码问题）

### 读取文件

```python
f = open("data.txt", "r", encoding="utf-8")

content = f.read()          # 读取全部内容（一个字符串）
line1 = f.readline()        # 读取一行（含换行符）
lines = f.readlines()       # 读取全部行（列表，每行含换行符）

f.close()                   # 用完必须关闭！
```

```python
# 逐行读取（推荐，适合大文件）
f = open("data.txt", "r", encoding="utf-8")
for line in f:
    print(line.strip())     # strip() 去掉换行符
f.close()
```

### 写入文件

```python
f = open("out.txt", "w", encoding="utf-8")
f.write("第一行\n")          # write 不自动加换行
f.write("第二行\n")
f.writelines(["a\n", "b\n"])   # 写入多行
f.close()
```

> ⚠️ `write()` **不会自动加换行**，需要手动加 `\n`。

### with 语句（推荐，自动关闭）

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
# 离开 with 块自动关闭文件，不需要 close()
```

### 注意：文件操作后必须关闭

```python
f = open("a.txt", "w")
f.write("hello")
f.close()       # 不 close 可能丢失数据
```

## 6.2 数据组织的维度

### 一维数据

有序、单行排列的数据，如：`[1, 2, 3, 4]`、成绩列表、城市列表。

### 二维数据

表格数据，由行和列组成，如：

```
姓名, 语文, 数学
张三, 90, 85
李四, 88, 92
```

### 一维数据的表示

```python
# 用列表表示
cities = ["武汉", "北京", "上海"]
# 用字符串表示（空格或逗号分隔）
s = "武汉,北京,上海"
```

### 二维数据的表示

```python
# 列表套列表（每行一个子列表）
data = [
    ["姓名", "语文", "数学"],
    ["张三", 90, 85],
    ["李四", 88, 92],
]
```

## 6.3 一维数据的处理

### 输入处理（读入一维数据）

```python
# 从键盘输入一行数字
nums = [int(x) for x in input().split()]   # "1 2 3 4" → [1,2,3,4]

# 从文件读取一维数据（每行一个数据）
with open("scores.txt", "r", encoding="utf-8") as f:
    scores = [int(line.strip()) for line in f]
```

### 常见操作

```python
scores = [85, 92, 78, 90, 88]
max(scores)          # 92
min(scores)          # 78
sum(scores)          # 433
sum(scores) / len(scores)   # 86.6 平均值
sorted(scores)       # 排序
scores.sort()        # 原地排序
```

## 6.4 二维数据的处理

```python
# 一个班级的成绩表：第0行是表头
data = [
    ["张三", 90, 85],
    ["李四", 88, 92],
    ["王五", 70, 75],
]

# 访问第 i 行第 j 列
print(data[1][2])     # 92（李四的数学）

# 遍历每一行
for row in data:
    print(row)

# 计算每人总分并追加到行尾
for row in data:
    row.append(row[1] + row[2])
print(data)
```

## 6.5 CSV 文件读写（必考）

CSV（逗号分隔值）：数据之间用逗号分隔，每行一条记录。

### 手动读写 CSV（考试要求的基本方法）

```python
# 写入 CSV：把二维数据写成 CSV 文件
data = [
    ["姓名", "语文", "数学"],
    ["张三", 90, 85],
    ["李四", 88, 92],
]
with open("scores.csv", "w", encoding="utf-8", newline="") as f:
    for row in data:
        f.write(",".join(map(str, row)) + "\n")

# 读取 CSV：逐行拆分
with open("scores.csv", "r", encoding="utf-8") as f:
    for line in f:
        row = line.strip().split(",")
        print(row)      # ['姓名', '语文', '数学'] ...
```

### 使用 csv 模块（推荐）

```python
import csv

# 读取
with open("scores.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# 写入
with open("out.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "成绩"])
    writer.writerow(["张三", 90])
    writer.writerows([["李四", 88], ["王五", 92]])
```

> ⚠️ **常错点**：
> - 读 CSV 后每行是字符串列表，数字需要 `int()`/`float()` 转换
> - 写 CSV 用 `newline=""` 避免出现多余空行（Windows 下）

## 6.6 JSON 文件（了解）

```python
import json

data = {"name": "张三", "scores": [90, 85]}

# 写入
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读取
with open("data.json", "r", encoding="utf-8") as f:
    d = json.load(f)
print(d["name"])
```

## 6.7 综合例题（考试高频题型）

```python
# 例1：读文件统计成绩，输出平均分和最高分
with open("scores.txt", "r", encoding="utf-8") as f:
    scores = [int(line.strip()) for line in f]
print(f"平均分：{sum(scores) / len(scores):.1f}")
print(f"最高分：{max(scores)}")

# 例2：处理 CSV 成绩表，输出不及格名单
with open("scores.csv", "r", encoding="utf-8") as f:
    next(f)                     # 跳过表头
    for line in f:
        name, chinese, math = line.strip().split(",")
        chinese, math = int(chinese), int(math)
        if chinese < 60 or math < 60:
            print(f"{name}: 语文{chinese} 数学{math}")

# 例3：读取文本文件，统计单词个数
with open("article.txt", "r", encoding="utf-8") as f:
    content = f.read()
words = content.split()
print(f"单词数：{len(words)}")
```
