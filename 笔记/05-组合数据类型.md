# 第五章 组合数据类型

> 对应大纲：组合数据类型基本概念、列表、元组、字典

## 5.1 组合数据类型概述

| 类型 | 是否有序 | 是否可变 | 元素可重复 | 表示 |
|------|---------|---------|-----------|------|
| 列表 list | ✅ 有序 | ✅ 可变 | ✅ | `[1, 2, 3]` |
| 元组 tuple | ✅ 有序 | ❌ 不可变 | ✅ | `(1, 2, 3)` |
| 字典 dict | ❌ 无序 | ✅ 可变 | 键不可重复 | `{"a": 1}` |
| 集合 set | ❌ 无序 | ✅ 可变 | ❌ 去重 | `{1, 2, 3}` |

> ⚠️ **必考**：
> - 列表可变，元组不可变
> - 字典的**键**必须是不可变类型（str、int、tuple 可以，list 不行）
> - 字符串也可以看作组合数据类型（有序、不可变）

## 5.2 列表 list（必考）

### 创建与索引切片

```python
lst = [1, 2, 3, 4, 5]
lst[0]        # 1
lst[-1]       # 5
lst[1:3]      # [2, 3]（含头不含尾）
lst[::2]      # [1, 3, 5]
lst[::-1]     # [5, 4, 3, 2, 1] 反转
list("abc")   # ['a', 'b', 'c'] 字符串转列表
[0] * 5       # [0, 0, 0, 0, 0]
```

### 列表方法（必考）

```python
lst = [1, 2, 3]
lst.append(4)        # 末尾追加 [1,2,3,4]
lst.insert(0, 0)     # 指定位置插入 [0,1,2,3,4]
lst.extend([5, 6])   # 末尾批量追加 [0,1,2,3,4,5,6]
lst.remove(1)        # 删除第一个值为1的元素
lst.pop()            # 删除并返回末尾元素
lst.pop(0)           # 删除并返回索引0的元素
lst.index(2)         # 元素2的索引
lst.count(2)         # 元素2出现次数
lst.sort()           # 原地升序排序
lst.sort(reverse=True)  # 原地降序
lst.reverse()        # 原地反转
lst.clear()          # 清空
sorted(lst)          # 返回新排序列表（不修改原列表）
```

> ⚠️ **高频考点**：
> - `sort()` 修改原列表，`sorted()` 返回新列表
> - `index()` 找不到元素报 `ValueError`；`count()` 找不到返回 0

### 列表的删除

```python
lst = [1, 2, 3, 4]
del lst[1]      # 按索引删除 [1,3,4]
del lst[0:2]    # 按切片删除
del lst         # 删除整个列表
```

### 列表推导式（了解，加分项）

```python
[x ** 2 for x in range(5)]        # [0, 1, 4, 9, 16]
[x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]
```

### 二维列表（必考）

```python
matrix = [[1, 2, 3],
          [4, 5, 6],
          [7, 8, 9]]
matrix[0][1]        # 2（第0行第1列）

# 遍历二维列表
for row in matrix:
    for x in row:
        print(x, end=" ")

# 按行求和
for row in matrix:
    print(sum(row))
```

> ⚠️ **必考**：`[[0] * 3] * 3` 创建的是同一行的引用！要用列表推导式：
> ```python
> bad = [[0] * 3] * 3      # 三个子列表是同一个对象！
> bad[0][0] = 1
> print(bad)               # [[1,0,0],[1,0,0],[1,0,0]] 全部变了！
>
> good = [[0] * 3 for _ in range(3)]   # 正确
> ```

## 5.3 元组 tuple

### 创建

```python
t = (1, 2, 3)
t2 = 1, 2, 3        # 不加括号也是元组
t3 = (1,)           # 单个元素必须加逗号！(1) 只是整数
t4 = ()             # 空元组
tuple([1, 2])       # (1, 2) 列表转元组
```

> ⚠️ **必考点**：`(1)` 是整数 1，`(1,)` 才是元组！

### 不可变性

```python
t = (1, 2, 3)
t[0] = 100      # TypeError！元组不能修改
t.append(4)     # AttributeError！元组没有 append
```

> ⚠️ 元组不可变，但有切片、索引、`in`、`+`、`*`、`count`、`index` 等操作（只读操作都可以）。

### 元组解包（必考）

```python
a, b, c = (1, 2, 3)      # a=1, b=2, c=3
x, y = y, x              # 交换变量
first, *rest = [1, 2, 3, 4]   # first=1, rest=[2,3,4]
```

### 列表与元组的转换

```python
lst = [1, 2, 3]
t = tuple(lst)          # (1, 2, 3)
lst2 = list(t)          # [1, 2, 3]
```

## 5.4 字典 dict（必考）

### 创建与访问

```python
d = {"name": "张三", "age": 20}
d["name"]        # "张三"
d["age"]         # 20
d.get("name")    # "张三"
d.get("score", 0)   # 键不存在返回默认值 0（不报错）
d["score"]       # KeyError！键不存在直接报错
```

> ⚠️ **必考点**：`d["不存在"]` 报 KeyError；`d.get("不存在")` 返回 None。

### 增加与修改

```python
d = {"name": "张三"}
d["age"] = 20          # 键不存在 → 新增
d["name"] = "李四"      # 键存在 → 修改
d.update({"city": "武汉", "age": 21})   # 批量更新
```

### 删除

```python
d = {"a": 1, "b": 2, "c": 3}
del d["a"]             # 删除键 a
d.pop("b")             # 删除并返回对应值
d.pop("x", "没有")      # 键不存在返回默认值，不报错
d.clear()              # 清空字典
```

### 遍历（必考）

```python
d = {"name": "张三", "age": 20}

for k in d:                    # 遍历键
    print(k)                   # name age

for v in d.values():           # 遍历值
    print(v)                   # 张三 20

for k, v in d.items():         # 遍历键值对
    print(k, v)
```

### 其他常用方法

```python
d = {"a": 1, "b": 2}
"a" in d          # True 判断键是否存在
len(d)            # 2
d.keys()          # 所有键
d.values()        # 所有值
d.items()         # 所有键值对
list(d)           # ['a', 'b'] 转成键列表
d2 = dict(a=1, b=2)   # 另一种创建方式
```

### 字典的键值要求

```python
d = {(1, 2): "元组可以", "abc": "字符串可以", 123: "整数可以"}
# d = {[1, 2]: "x"}    # TypeError！列表不可哈希，不能当键
```

## 5.5 集合 set（了解）

```python
s = {1, 2, 2, 3}        # {1, 2, 3} 自动去重
s = set([1, 2, 2])      # {1, 2}
s.add(4)                # 添加
s.remove(1)             # 删除（不存在报 KeyError）
s.discard(99)           # 删除（不存在不报错）
s | {5}                 # 并集
s & {2, 3}              # 交集
s - {2}                 # 差集

# 去重的经典用法
lst = [1, 2, 2, 3, 3, 3]
print(list(set(lst)))   # [1, 2, 3]
```

## 5.6 类型转换总结

```python
list("abc")            # ['a','b','c']
tuple([1, 2])          # (1, 2)
set([1, 1, 2])         # {1, 2}
list({"a": 1})         # ['a'] 字典转列表得到键
"".join(["a", "b"])    # 'ab' 列表转字符串
str([1, 2])            # "[1, 2]"
```

## 5.7 综合例题

```python
# 例1：统计字符串中每个字符出现的次数（必考题型）
s = "hello world"
counts = {}
for ch in s:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)

# 例2：列表去重并保持原顺序
lst = [3, 1, 2, 3, 1, 4]
result = []
for x in lst:
    if x not in result:
        result.append(x)
print(result)   # [3, 1, 2, 4]

# 例3：求列表最大值和出现次数（不使用max）
lst = [3, 7, 2, 7, 9, 7]
max_val = lst[0]
for x in lst:
    if x > max_val:
        max_val = x
print("最大值：", max_val, "出现次数：", lst.count(max_val))

# 例4：字典按值排序
scores = {"张三": 85, "李四": 92, "王五": 78}
ranked = sorted(scores.items(), key=lambda x: x[1], reverse=True)
print(ranked)   # [('李四', 92), ('张三', 85), ('王五', 78)]
```
