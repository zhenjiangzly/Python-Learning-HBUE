## 2.1 数字类型

### 整数类型 int

- 任意大小，无范围限制
- 进制表示：`0b`（二进制）、`0o`（八进制）、`0x`（十六进制）
- 进制的英文表示：`bin(x)` 转二进制、`oct(x)` 转八进制、`hex(x)` 转十六进制

```python
print(0b1010)   # 10
print(0o12)     # 10
print(0x0A)     # 10
print(bin(10))  # 0b1010
print(oct(10))  # 0o12
print(hex(10))  # 0xa
```

### 浮点数类型 float

- 有精度限制，**浮点数运算存在误差**

```python
print(0.1 + 0.2)   # 0.30000000000000004（不是 0.3！）
print(round(0.1 + 0.2, 1))   # 0.3，四舍五入到1位小数
```

- 科学计数法：`1e3` = 1000.0，`5e-2` = 0.05

### 复数类型 complex

```python
z = 3 + 4j
print(z.real)    # 3.0 实部
print(z.imag)    # 4.0 虚部
```

## 2.2 数值运算操作符（必考）

| 操作符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加 | `7 + 2` | 9 |
| `-` | 减 | `7 - 2` | 5 |
| `*` | 乘 | `7 * 2` | 14 |
| `/` | 除（**结果是浮点数**） | `7 / 2` | 3.5 |
| `//` | 整除（向下取整） | `7 // 2` | 3 |
| `%` | 取余 | `7 % 2` | 1 |
| `**` | 幂 | `2 ** 3` | 8 |

> ⚠️ **必考点**：
> - `/` 永远返回浮点数：`4 / 2` → `2.0`
> - 整除向下取整：`-7 // 2` → **-4**（不是 -3！）
> - 取余符号跟随除数：`-7 % 2` → **1**（因为 -4*2 = -8，-7 - (-8) = 1）

### 运算优先级

括号 → 幂 `**` → 乘除取余 `* / // %` → 加减 `+ -`

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
print(2 ** 3 ** 2)    # 512，幂运算右结合：2**(3**2)
```

## 2.3 数值运算函数（必考）

| 函数 | 含义 | 示例 |
|------|------|------|
| `abs(x)` | 绝对值 | `abs(-5)` → 5 |
| `divmod(a, b)` | 返回 (商, 余数) | `divmod(7, 2)` → (3, 1) |
| `pow(a, b)` | a 的 b 次幂 | `pow(2, 3)` → 8 |
| `round(x, n)` | 四舍五入到 n 位 | `round(3.14159, 2)` → 3.14 |
| `max(a, b, ...)` | 最大值 | `max(1, 5, 3)` → 5 |
| `min(a, b, ...)` | 最小值 | `min(1, 5, 3)` → 1 |
| `int(x)` | 转整数 | `int("42")` → 42 |
| `float(x)` | 转浮点数 | `float("3.5")` → 3.5 |
| `str(x)` | 转字符串 | `str(42)` → "42" |

## 2.4 真假无：True / False / None

- `True`、`False` 是布尔类型，参与运算时当作 1 和 0
- `None` 表示"空值"，不是 False

```python
print(True + 1)    # 2
print(False * 10)  # 0
print(bool(0))     # False
print(bool(""))    # False
print(bool(None))  # False
print(bool([1]))   # True，非空即可
```

> ⚠️ 判定 False 的值：`0、0.0、""、[]、()、{}、None` 均为 False，其他为 True。

## 2.5 字符串类型及格式化（必考）

### 索引与切片

```python
s = "HelloWorld"
# 索引：正向从 0 开始，反向从 -1 开始
print(s[0])       # 'H'
print(s[-1])      # 'd'
# 切片：s[start:end:step]，含头不含尾
print(s[0:5])     # 'Hello'（取索引0~4）
print(s[:5])      # 'Hello'
print(s[5:])      # 'World'
print(s[::2])     # 'HloWrd'（隔一个取一个）
print(s[::-1])    # 'dlroWolleH'（反转）
```

> ⚠️ **必考**：切片"含头不含尾"。`s[0:5]` 不含索引 5。

### format() 格式化（必考）

```python
print("{} 和 {}".format("苹果", "香蕉"))      # 苹果 和 香蕉
print("{1} 和 {0}".format("苹果", "香蕉"))    # 香蕉 和 苹果（按序号）
print("{:.2f}".format(3.14159))              # 3.14（两位小数）
print("{:>5}".format("ab"))                  # '   ab'（右对齐，宽5）
print("{:<5}".format("ab"))                  # 'ab   '（左对齐）
print("{:^5}".format("ab"))                  # ' ab  '（居中）
print("{:05d}".format(42))                   # '00042'（补0）
print("{:,}".format(1234567))                # '1,234,567'（千分位）
```

### f-string（Python 3.6+，必考）

```python
name = "张三"
age = 20
print(f"我叫{name}，今年{age}岁")       # 我叫张三，今年20岁
print(f"圆周率约等于{3.14159:.2f}")     # 圆周率约等于3.14
```

### 转义字符

`\n` 换行、`\t` 制表符、`\\` 反斜杠、`\'` 单引号、`\"` 双引号

## 2.6 字符串类型的操作（必考）

### 字符串操作符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `+` | 连接 | `"ab" + "cd"` → "abcd" |
| `*` | 重复 | `"ab" * 3` → "ababab" |
| `in` | 判断子串 | `"a" in "abc"` → True |
| `not in` | 判断非子串 | `"x" not in "abc"` → True |

### 常用字符串函数与方法

```python
s = "Hello, World"
len(s)                     # 12 长度
ord("a")                   # 97 字符转Unicode码
chr(97)                    # 'a' Unicode码转字符
s.upper()                  # 转大写
s.lower()                  # 转小写
s.title()                  # 每个单词首字母大写
s.strip()                  # 去除两端空格
s.split(",")               # ['Hello', ' World'] 按分隔符拆分成列表
",".join(["a", "b", "c"])  # 'a,b,c' 列表连接成字符串
s.replace("World", "HBUE") # 'Hello, HBUE'
s.count("l")               # 3 统计出现次数
s.index("o")               # 4 查找子串位置（找不到报错）
s.find("o")                # 4 查找子串位置（找不到返回-1）
s.startswith("He")         # True 是否以指定串开头
s.endswith("ld")           # True 是否以指定串结尾
```

## 2.7 类型判断和类型转换

```python
type(10)                 # <class 'int'>
type("abc")              # <class 'str'>
isinstance(10, int)      # True

```

## 2.8 逻辑运算和比较运算

### 比较运算符

`==` 等于、`!=` 不等于、`>`、`<`、`>=`、`<=`

### 逻辑运算符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `and` | 与（全真才真） | `True and False` → False |
| `or` | 或（一真即真） | `True or False` → True |
| `not` | 非（取反） | `not True` → False |

### 短路运算（常考）

```python
a = 0 or 5        # 5（左边为假，取右边）
b = 3 or 5        # 3（左边为真，直接取左边）
c = 0 and 5       # 0
d = 3 and 5       # 5
```

> ⚠️ `and`/`or` 返回的不一定是 True/False，而是**参与运算的值**。
> 常见应用：`x = input() or "默认值"`。
