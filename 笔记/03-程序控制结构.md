# 第三章 程序的控制结构

> 对应大纲：分支结构、循环结构、循环控制、异常处理

## 3.1 分支结构

### 单分支 if

```python
score = int(input("请输入成绩："))
if score >= 60:
    print("及格")
```

### 二分支 if-else

```python
score = int(input("请输入成绩："))
if score >= 60:
    print("及格")
else:
    print("不及格")
```

> 💡 简洁写法（条件表达式）：
> ```python
> result = "及格" if score >= 60 else "不及格"
> ```

### 多分支 if-elif-else（必考）

```python
score = int(input("请输入成绩："))
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 70:
    print("中等")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

> ⚠️ **常错点**：
> - `elif` 判断的先后顺序很重要，**上到下逐个判断，命中即止**
> - `if score >= 90` 写在 `if score >= 60` 前面（先判断高分）
> - 条件后面必须有**冒号**，代码块必须**缩进**
> - 使用 `and` / `or` / `not` 组合条件

```python
age = int(input("请输入年龄："))
if age >= 18 and age < 60:
    print("成年人")
```

### 条件表达式（三目运算）

```python
a, b = 5, 8
max_value = a if a > b else b   # 取较大值
print(max_value)                # 8
```

## 3.2 循环结构

### for 遍历循环（必考）

```python
# 遍历 range
for i in range(5):        # 0,1,2,3,4
    print(i)

for i in range(1, 6):     # 1,2,3,4,5（含头不含尾）
    print(i)

for i in range(1, 10, 2): # 1,3,5,7,9（步长2）
    print(i)

# 遍历字符串
for ch in "Hello":
    print(ch)             # 逐个字符输出

# 遍历列表
for x in [10, 20, 30]:
    print(x)

# 带索引遍历
for i, ch in enumerate("abc"):
    print(i, ch)          # 0 a / 1 b / 2 c
```

> ⚠️ `range(n)` 生成 0~n-1；`range(a, b)` 生成 a~b-1，**含头不含尾**。

### 累加求和（经典题型）

```python
total = 0
for i in range(1, 101):
    total += i
print(total)              # 5050

# 或者直接用内置函数
print(sum(range(1, 101)))  # 5050
```

### while 无限循环（必考）

```python
n = 1
while n <= 100:
    n += 1
print(n)                  # 101

# 死循环（注意要有跳出条件！）
while True:
    x = input("输入q退出：")
    if x == "q":
        break
```

> ⚠️ **必考点**：`while` 循环中变量必须在循环体内**改变**，否则死循环。
> ```python
> i = 0
> while i < 10:
>     print(i)   # 少了 i += 1 → 死循环！
> ```

## 3.3 循环控制（必考）

### break —— 跳出整个循环

```python
for i in range(1, 10):
    if i == 5:
        break            # 循环立即结束
    print(i)             # 输出 1 2 3 4
```

### continue —— 跳过本次循环

```python
for i in range(1, 10):
    if i % 2 == 0:
        continue         # 跳过偶数
    print(i)             # 输出 1 3 5 7 9
```

### 循环与 else 搭配（高频考点）

- 循环**正常结束**（没有被 break）时，执行 else 块
- 被 break 打断时，**不执行** else 块

```python
# 例1：break 打断 → else 不执行
for i in range(5):
    if i == 3:
        break
    print(i)             # 0 1 2
else:
    print("循环正常结束")  # 不输出

# 例2：正常结束 → else 执行
for i in range(5):
    print(i)             # 0 1 2 3 4
else:
    print("循环正常结束")  # 输出
```

```python
# 经典应用：判断素数
n = int(input("请输入一个整数："))
for i in range(2, n):
    if n % i == 0:
        print(f"{n} 不是素数")
        break
else:
    print(f"{n} 是素数")
```

## 3.5 异常处理（必考）

### try-except 基本结构

```python
try:
    a = int(input("请输入整数："))
    b = 10 / a
    print(b)
except ZeroDivisionError:
    print("除数不能为 0")
except ValueError:
    print("请输入数字")
except Exception:
    print("其他错误")
```

### 完整结构：try-except-else-finally

```python
try:
    a = int(input("请输入整数："))
    b = 10 / a
except ZeroDivisionError:
    print("除数不能为 0")
else:
    print("没出错，结果：", b)   # 无异常时执行
finally:
    print("无论如何都会执行")    # 有无异常都执行
```

> ⚠️ **必考点**：
> - `else`：try 块**无异常**时执行
> - `finally`：**无论是否异常**都会执行
> - 可以捕获多个异常：`except (ValueError, TypeError):`
> - 异常类层次：`ZeroDivisionError`、`ValueError`、`TypeError`、`IndexError`、`KeyError`、`FileNotFoundError` 都是 `Exception` 的子类

### 常见异常类型

| 异常 | 触发场景 |
|------|----------|
| ZeroDivisionError | 除数为 0 |
| ValueError | 值类型不对（如 int("abc")） |
| TypeError | 类型不匹配（如 "a" + 1） |
| IndexError | 索引越界 |
| KeyError | 字典键不存在 |
| FileNotFoundError | 文件不存在 |

### 主动抛出异常

```python
def check_age(age):
    if age < 0:
        raise ValueError("年龄不能为负数")
    return age
```

## 3.6 综合例题

```python
# 例1：猜数字游戏
import random
secret = random.randint(1, 100)
while True:
    guess = int(input("猜一个1-100的数："))
    if guess > secret:
        print("大了")
    elif guess < secret:
        print("小了")
    else:
        print("猜中了！")
        break

# 例2：统计输入正数之和，输入负数结束
total = 0
while True:
    n = int(input("请输入（负数结束）："))
    if n < 0:
        break
    total += n
print("总和：", total)

# 例3：输入整数n，求n!（阶乘）
n = int(input("请输入n："))
result = 1
for i in range(1, n + 1):
    result *= i
print(result)
```
