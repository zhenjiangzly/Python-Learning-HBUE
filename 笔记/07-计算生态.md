## 7.1 turtle 库（海龟绘图，必考）

> turtle 是考试**必考**的标准库，操作题中经常出现画图题。

### 画布与坐标系

- 画布中央是原点 (0, 0)
- 水平向右为 x 轴正方向（0°），逆时针旋转为正角度

### 常用函数

| 函数 | 功能 |
|------|------|
| `turtle.setup(w, h)` | 设置窗口大小 |
| `turtle.forward(d)` / `fd(d)` | 前进 d 像素 |
| `turtle.backward(d)` / `bk(d)` | 后退 d 像素 |
| `turtle.right(angle)` / `rt(angle)` | 右转 angle 度 |
| `turtle.left(angle)` / `lt(angle)` | 左转 angle 度 |
| `turtle.penup()` / `pu()` | 抬起画笔（移动不留痕迹） |
| `turtle.pendown()` / `pd()` | 落下画笔 |
| `turtle.pensize(n)` / `width(n)` | 画笔粗细 |
| `turtle.pencolor(c)` | 画笔颜色 |
| `turtle.color(c)` | 画笔和填充颜色 |
| `turtle.fillcolor(c)` | 填充颜色 |
| `turtle.begin_fill()` | 开始填充 |
| `turtle.end_fill()` | 结束填充 |
| `turtle.goto(x, y)` | 移动到 (x, y) |
| `turtle.circle(r, extent)` | 画圆（extent 为角度，360 为整圆） |
| `turtle.speed(n)` | 速度 1-10 |
| `turtle.done()` | 结束绘图，窗口不关闭 |

### 经典示例：正方形

```python
import turtle

turtle.pensize(3)
turtle.pencolor("blue")
for _ in range(4):
    turtle.forward(100)
    turtle.right(90)
turtle.done()
```

### 经典示例：彩色圆形

```python
import turtle

turtle.speed(10)
colors = ["red", "green", "blue", "yellow", "purple"]
for i in range(5):
    turtle.pencolor(colors[i])
    turtle.circle(50)
    turtle.right(72)
turtle.done()
```

### 经典示例：填充五角星

```python
import turtle

turtle.fillcolor("red")
turtle.begin_fill()
for _ in range(5):
    turtle.forward(100)
    turtle.right(144)      # 五角星外角 144°
turtle.end_fill()
turtle.done()
```

> ⚠️ 记住五角星的转向角是 **144°**，正多边形的外角是 360/n。

## 7.2 random 库（必考）

| 函数 | 功能 | 示例 |
|------|------|------|
| `random.random()` | 随机浮点数 [0, 1) | `0.317...` |
| `random.randint(a, b)` | 随机整数 [a, b]**含两端** | `random.randint(1, 6)` → 1~6 |
| `random.randrange(a, b, s)` | 步进随机整数，含 a 不含 b | `random.randrange(0, 10, 2)` → 偶数 |
| `random.uniform(a, b)` | 随机浮点数 [a, b] | `random.uniform(1, 10)` |
| `random.choice(seq)` | 从序列随机取一个 | `random.choice(["石头","剪刀","布"])` |
| `random.choices(seq, k=n)` | 随机取 n 个（可重复） | `random.choices("AB", k=3)` |
| `random.sample(seq, k=n)` | 随机取 n 个（不重复） | `random.sample(range(10), 3)` |
| `random.shuffle(seq)` | 打乱列表（原地） | `random.shuffle(lst)` |

```python
import random

# 猜数字游戏
secret = random.randint(1, 100)

# 随机点名
students = ["张三", "李四", "王五"]
print(random.choice(students))

# 随机密码（6位数字）
print("".join(str(random.randint(0, 9)) for _ in range(6)))

# 彩票双色球：从1-33取6个不重复
print(sorted(random.sample(range(1, 34), 6)))
```

> ⚠️ `random.randint(a, b)` **含 b**；`random.randrange(a, b)` **不含 b**。常考！

## 7.3 time 库（必考）

| 函数 | 功能 |
|------|------|
| `time.time()` | 当前时间戳（1970年以来秒数） |
| `time.ctime()` | 可读时间字符串 |
| `time.localtime()` | 本地时间元组（struct_time） |
| `time.strftime(fmt, t)` | 格式化时间（**必考**） |
| `time.strptime(str, fmt)` | 字符串解析为时间元组 |
| `time.sleep(sec)` | 程序暂停 sec 秒 |
| `time.perf_counter()` | 计时用，返回高精度时间 |

### strftime 格式符（必考）

| 格式符 | 含义 | 示例 |
|--------|------|------|
| `%Y` | 四位年份 | 2025 |
| `%y` | 两位年份 | 25 |
| `%m` | 月份 01-12 | 08 |
| `%d` | 日期 01-31 | 12 |
| `%H` | 小时 00-23 | 14 |
| `%M` | 分钟 00-59 | 30 |
| `%S` | 秒 00-59 | 45 |
| `%A` | 星期全称 | Wednesday |
| `%a` | 星期缩写 | Wed |
| `%B` | 月份全称 | August |
| `%b` | 月份缩写 | Aug |

```python
import time

print(time.time())          # 1778654321.123456
print(time.ctime())         # Wed Aug 12 14:30:45 2026

# 格式化当前时间
t = time.localtime()
print(time.strftime("%Y-%m-%d %H:%M:%S", t))   # 2026-08-12 14:30:45
print(time.strftime("%Y年%m月%d日", t))         # 2026年08月12日

# 计时（程序运行耗时）
start = time.perf_counter()
time.sleep(1)
end = time.perf_counter()
print(f"耗时：{end - start:.2f} 秒")
```

> ⚠️ 常考点：`%Y` 是四位数年份，`%y` 是两位数；`strftime(格式, 时间)` 参数顺序不能反。

## 7.5 pip 工具（必考）

### 安装第三方库

```bash
pip install 库名             # 安装最新版
pip install 库名==1.2.3     # 指定版本
pip install 库名 -i https://pypi.tuna.tsinghua.edu.cn/simple   # 国内镜像加速
```

### 常用命令

```bash
pip list                     # 查看已安装库
pip show 库名                # 查看库信息
pip uninstall 库名           # 卸载
pip install --upgrade 库名   # 升级
```

> ⚠️ 常考点：`pip install jieba` 是在**命令行**中执行，不是在 Python 代码里！

## 7.6 第三方库（必考）

### jieba 库（中文分词，必考）

```python
import jieba

text = "湖北经济学院是一所好大学"
print(jieba.lcut(text))      # 精确模式分词，返回列表
# ['湖北', '经济', '学院', '是', '一所', '好大学']

print(jieba.lcut(text, cut_all=True))    # 全模式
print(jieba.lcut_for_search(text))       # 搜索引擎模式

print(len(jieba.lcut(text)))  # 词数统计
```

> ⚠️ 常考点：`jieba.lcut()` 精确分词是**最常用**的，返回**列表**。

### PyInstaller 库（打包 exe）

```bash
pip install pyinstaller
pyinstaller -F 程序.py        # 打包成单个 exe 文件
pyinstaller -w 程序.py        # 不显示命令行窗口（GUI程序）
pyinstaller -F -i 图标.ico 程序.py   # 带图标
```

> ⚠️ 常考点：`-F` 生成单个可执行文件；打包命令在命令行执行。

### NumPy 库（科学计算，了解）

```python
import numpy as np

a = np.array([1, 2, 3])       # 创建数组
b = np.array([[1, 2], [3, 4]])   # 二维数组（矩阵）
a + 1                # 每个元素加1: array([2,3,4])
a * 2                # array([2,4,6]) 广播运算

np.max(a)            # 3
np.random.randint(0, 10, 5)    # 5个0-9随机整数数组

np.zeros((2, 3))     # 2行3列全0
np.ones((2, 3))      # 全1
```

## 7.8 综合例题

```python
# 例1：随机生成4位验证码
import random
import string

chars = string.ascii_uppercase + string.digits
code = "".join(random.choice(chars) for _ in range(4))
print(code)

# 例2：用 turtle 画风车（多扇形）
import turtle

turtle.speed(8)
for i in range(4):
    turtle.circle(80, 90)      # 画90°弧
    turtle.left(90)
turtle.done()

# 例3：中文文本词频统计（必考题型）
import jieba

with open("article.txt", "r", encoding="utf-8") as f:
    text = f.read()
words = jieba.lcut(text)
counts = {}
for w in words:
    if len(w) > 1:            # 排除单个字
        counts[w] = counts.get(w, 0) + 1
top10 = sorted(counts.items(), key=lambda x: x[1], reverse=True)[:10]
for word, count in top10:
    print(word, count)
```
