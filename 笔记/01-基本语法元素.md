## 1.1 程序的格式框架

### 缩进（Indentation）

Python 用**缩进**表示代码块层级，**缩进必须一致**（通常 4 个空格或 1 个 Tab）。

```python
if 3 > 2:        # 条件为真
    print("成立") # 缩进的代码属于 if 块
    print("还是 if 块内")
print("缩进结束，不受 if 控制")
```

> ⚠️ 考试常考：同一层代码块缩进不一致会报 `IndentationError`；缩进决定了代码属于哪个分支。

### 注释（Comment）

- 单行注释：`#` 开头
- 多行注释：`'''...'''` 或 `"""..."""`

```python
# 这是单行注释
'''
这是多行注释
'''
```

### 代码行与续行

```python
total = 1 + 2 + 3 \
        + 4 + 5          # 反斜杠续行
print(total)             # 15
```

> ⚠️ 每行一条语句；多个语句用 `;` 分隔（不推荐但考试会考）。

```python
a = 1; b = 2; c = 3      # 合法，但不推荐
```

## 1.2 变量与命名

### 命名规则（必考）

1. 由**字母、数字、下划线**组成
2. **不能以数字开头**
3. **不能使用保留字**（如 if、for、while、def 等）
4. 区分大小写：`Name` 与 `name` 是两个不同变量
5. 建议使用有意义的英文命名

```python
student_name = "张三"   # 合法
_private = 1            # 合法（以下划线开头）
2name = 1               # 非法：不能以数字开头
my-name = 1             # 非法：不能有减号
class = 1               # 非法：class 是保留字
```

### 保留字（考试重点）

考试常考以下保留字：`if, elif, else, for, while, def, return, import, from, class, in, is, not, and, or, True, False, None, global, lambda, try, except, break, continue, pass, with, as, del, yield, raise, finally, nonlocal`

> ⚠️ 常错点：`print`、`input`、`type`、`range` **不是保留字**（它们是内置函数）。

### 变量的赋值

```python
a = 10                 # 简单赋值
a, b = 1, 2            # 同步赋值（a=1, b=2）
a = b = 0              # 链式赋值（都等于0）
a, b = b, a            # 交换两个变量（元组解包）
```

## 1.3 数据类型总览

Python 中**变量没有固定类型**，类型取决于赋给它的值（动态类型）：

| 类型 | 名称 | 例子 |
|------|------|------|
| int | 整数 | `42` |
| float | 浮点数 | `3.14` |
| complex | 复数 | `1+2j` |
| str | 字符串 | `"hello"` |
| bool | 布尔 | `True` |
| list | 列表 | `[1, 2, 3]` |
| tuple | 元组 | `(1, 2)` |
| dict | 字典 | `{"a": 1}` |
| set | 集合 | `{1, 2}` |

## 1.4 基本输入输出函数

### input() —— 输入

```python
name = input("请输入姓名：")  # 返回的永远是字符串！
age = input("请输入年龄：")   # "18"，是 str 类型
```

> ⚠️ **必考**：`input()` 返回字符串类型，参与数值运算前必须先转换：
> ```python
> age = int(input("请输入年龄："))   # 转成整数
> ```

### eval() —— 计算字符串中的表达式

```python
s = "3 + 5"
print(eval(s))     # 8
x = eval("7")
print(x)           # 7，且是 int 类型
```

> ⚠️ **高频考点**：`eval(input("..."))` 会直接把输入转换成对应类型。
> ```python
> n = eval(input("请输入数字："))   # 输入 5 → n 是 int；输入 3.5 → n 是 float
> ```

### print() —— 输出

```python
print("hello")          # hello
print(1, 2, 3)          # 1 2 3（默认空格分隔）
print(1, 2, 3, sep="-") # 1-2-3
print("end", end="")    # 不换行
print()                 # 输出空行
```

> ⚠️ `print()` 默认 `end="\n"`（换行）、`sep=" "`（空格分隔）。

## 1.5 Python 语言的特点

1. 面向对象、解释型、动态数据类型的高级语言
2. 代码简洁、可读性强、可移植性好
3. 拥有庞大的标准库与第三方库（计算生态）
4. 运行效率低于 C/C++，但开发效率高
5. Python 3 与 Python 2 不兼容，考试使用 Python 3

## 1.6 常见易错点

| 错误 | 示例 | 原因 |
|------|------|------|
| 忘记缩进 | `if 1: print("a")` 下一行没缩进 | 同一代码块必须缩进 |
| 用保留字做变量 | `for = 1` | for 是保留字 |
| input 当数字用 | `input("年龄") + 1` | input 返回 str，需 int() 转换 |
| 变量拼写不一致 | `Student` 和 `student` | Python 区分大小写 |
| 缩进混合 Tab/空格 | 同块 Tab 与空格混用 | 必须统一 |
