## 选择题

**1. 以下哪个是列表的表示方法？**

**6. 以下哪个是元组？**

## 参考答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | B | 列表用方括号 `[]`；元组圆括号，集合花括号 |
| 2 | A | 切片含头不含尾：索引1~2 = [2, 3] |
| 3 | C | append 在末尾追加元素 |
| 4 | B | sort() 原地升序排序，修改原列表 |
| 5 | A | sorted() 返回新列表，不修改原列表 |
| 6 | B | 元组用圆括号 `()` |
| 7 | B | `(1)` 只是整数 1，`(1,)` 才是元组 |
| 8 | B | 元组不可变，赋值抛 TypeError |
| 9 | B | 元组解包按顺序：a=1, b=2, c=3 |
| 10 | A | 通过键取字典值 |
| 11 | B | 键已存在则修改值 |
| 12 | B | 键不存在直接取 → KeyError |
| 13 | C | get 带默认值，键不存在返回默认值 0 |
| 14 | B | 遍历字典默认遍历键 |
| 15 | B | set 去重后 {1,2,3}，长度 3 |
| 16 | A | pop() 默认删除末尾元素 |
| 17 | A | pop(0) 删除并返回索引0的元素（值1） |
| 18 | A | del 按索引删除，删除索引1的元素 2 |
| 19 | C | 键必须不可变（可哈希），元组可以，列表/字典/集合不行 |
| 20 | A | 遍历值求和：1+2+3=6 |
| 21 | B | list() 把字符串拆成字符列表 |
| 22 | A | 元组支持 + 连接 |
| 23 | A | [0]*3 = [0,0,0]，赋索引0不影响其他元素 |
| 24 | A | split 返回列表 |
| 25 | B | max 按值排序取键："李四"得分95最大 |
| 26 | C | 第1行第0列 = 3 |
| 27 | A | pop("a") 删除键 a，剩 {"b": 2} |
| 28 | A | count 统计元素出现次数，2 出现 1 次 |
| 29 | A | 0²,1²,2²,3² = 0,1,4,9 |
| 30 | C | update 批量新增 b、c，共 3 个键 |
