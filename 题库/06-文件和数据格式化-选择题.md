# 第六章 文件和数据格式化 选择题

> 参考答案在文末。

## 选择题

**1. 打开文件只读的模式是（　）。**
A. "w"
B. "r"
C. "a"
D. "x"

**2. 以 "w" 模式打开已存在的文件，会（　）。**
A. 保留原内容，在末尾追加
B. 清空原内容，从头写入
C. 报错
D. 只读

**3. 以 "a" 模式写入文件，会在（　）写入。**
A. 文件开头
B. 文件末尾
C. 覆盖中间
D. 报错

**4. 以下哪个语句能安全地打开文件并自动关闭？**
A. `f = open("a.txt", "r")`
B. `with open("a.txt", "r") as f:`
C. `open("a.txt", "r")`
D. `f = file("a.txt")`

**5. `f.readline()` 的返回值是（　）。**
A. 文件的全部内容
B. 一行内容（含换行符）
C. 所有行组成的列表
D. 单个字符

**6. `f.readlines()` 的返回值是（　）。**
A. 一个字符串
B. 一个列表，每个元素是一行
C. 一个元组
D. 整数

**7. 以下代码的输出结果是（　）。**

```python
with open("test.txt", "w") as f:
    f.write("123")
```

A. 写入 "123"（不带换行）
B. 写入 "123\n"
C. 报错
D. 无效果

**8. 读取中文文件时，为避免乱码，应指定（　）。**
A. `encoding="gbk"`
B. `encoding="utf-8"`
C. `newline=""`
D. `mode="rb"`

**9. 以下代码的输出结果是（　）。**

```python
s = "a,b,c"
print(len(s.split(",")))
```

A. 1
B. 3
C. 5
D. 错误

**10. 一维数据在 Python 中最常用（　）表示。**
A. 字典
B. 列表

**11. 二维数据在 Python 中最常用（　）表示。**
A. 嵌套列表（列表的列表）

C. 字符串
D. 集合

```python
data = [["a", 1], ["b", 2]]
print(data[1][1])
```

A. "a"

C. "b"

**13. 执行 `f = open("a.txt", "w")` 后，必须执行（　）关闭文件。**
A. `f.end()`
B. `f.close()`
C. `f.stop()`
D. `close(f)`

**14. 逐行读取文件的最佳方式是（　）。**
A. `content = f.read()` 后用 split
B. `for line in f:`
C. 反复调用 f.close()
D. `f.readlines()[0]`

**15. CSV 文件中，数据之间默认用（　）分隔。**
A. 空格
B. 制表符
C. 逗号
D. 分号

**16. 以下代码的功能是（　）。**

```python
with open("scores.csv", "r", encoding="utf-8") as f:
    for line in f:
        row = line.strip().split(",")
        print(row)
```

A. 读取 CSV 并输出每一行拆分的列表
B. 写入 CSV
C. 统计行数
D. 删除文件

**17. `f.read()` 的返回值是（　）。**
A. 文件全部内容的一个字符串
B. 一个字符列表
C. 每行的列表
D. 整数

**18. 关于 `strip()` 方法，下列说法正确的是（　）。**
A. 去除字符串两端的空白字符
B. 去除中间的空白字符
C. 把字符串拆成列表
D. 把字符串转大写

**19. 写入多行文件，代码正确的是（　）。**

```python
with open("a.txt", "w", encoding="utf-8") as f:
    f.writelines(["第一行\n", "第二行\n"])
```

A. 正确，写入两行
B. 错误，writelines 不存在
C. 只写一行
D. 报错，需要逐行 write

**20. 以下代码执行后，文件内容为（　）。**

```python

    f.write("1")
    f.write("2")
```

B. "2"
C. "12"
D. "1\n2"

**21. 使用 csv 模块读取文件时，正确写法是（　）。**

**22. 以下哪个不是打开文件的合法模式？**
A. "r+"
B. "wb"
C. "rt"
D. "e"

**23. 以下代码的输出结果是（　）。**

```python
data = [["姓名", "分数"], ["张三", 90], ["李四", 88]]
print(len(data))
```

A. 2
B. 3
C. 4
D. 5

**24. 文件读取中，`f.seek(0)` 的作用是（　）。**
A. 把文件指针移到开头
B. 删除文件
C. 关闭文件
D. 打开文件

**25. 以下代码的功能是（　）。**

```python
with open("a.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
count = len(lines)
```

A. 统计文件行数
B. 统计文件字数
C. 读取第一行
D. 复制文件

## 参考答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | B | "r" 是只读模式，文件必须存在 |
| 2 | B | "w" 模式清空原内容后写入 |
| 3 | B | "a" 追加模式在文件末尾写入 |
| 4 | B | with 语句自动管理文件关闭 |
| 5 | B | readline 读取一行（含 \n） |
| 6 | B | readlines 返回所有行的列表 |
| 7 | A | write 不会自动加换行符 |
| 8 | B | UTF-8 编码处理中文 |
| 9 | B | "a,b,c".split(",") = ["a","b","c"]，长度3 |
| 10 | B | 一维数据用列表表示 |
| 11 | A | 二维数据用列表嵌套列表 |
| 12 | D | 第1行第1列 = 2 |
| 13 | B | close() 关闭文件 |
| 14 | B | `for line in f` 逐行读取最简洁高效 |
| 15 | C | CSV = Comma-Separated Values，逗号分隔 |
| 16 | A | 逐行拆分逗号输出列表 |
| 17 | A | read 返回整个内容字符串 |
| 18 | A | strip 去除两端空白（含 \n） |
| 19 | A | writelines 接受字符串列表并写入 |
| 20 | C | 两次 write 追加写入 "12"（无换行） |
| 21 | A | csv.reader 返回迭代器，逐行是列表 |
| 22 | D | 没有 "e" 这种模式 |
| 23 | B | 3 行：表头 + 2 条数据 |
| 24 | A | seek(0) 将指针移到文件开头 |
| 25 | A | 行数 = lines 列表长度 |
