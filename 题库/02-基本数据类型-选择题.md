# 第二章 基本数据类型 选择题

> 参考答案在文末。

## 选择题

**1. 表达式 `7 // 2` 的值是（　）。**
A. 3.5
B. 3
C. 4
D. 1

**2. 表达式 `-7 // 2` 的值是（　）。**
A. -3.5
B. -3
C. -4
D. 3

**3. 表达式 `7 % 2` 的值是（　）。**
A. 3.5
B. 3
C. 1
D. 0

**4. 表达式 `4 / 2` 的类型是（　）。**
A. int
B. float
C. str
D. bool

**5. 表达式 `2 ** 3 ** 2` 的值是（　）。**
A. 64
B. 512
C. 36
D. 错误

**6. 表达式 `divmod(7, 2)` 的值是（　）。**
A. (3, 1)
B. (3.5, 0)
C. (1, 3)
D. (3, 2)

**7. `round(3.14159, 2)` 的结果是（　）。**
A. 3.1
B. 3.14
C. 3.15
D. 3.141

**8. 表达式 `int("101", 2)` 的结果是（　）。**
A. 101
B. 5
C. 2
D. 错误

**9. 字符串 `s = "HelloWorld"`，`s[0:5]` 的结果是（　）。**
A. "Hello"
B. "World"
C. "elloW"
D. "HelloWorld"

**10. `s = "HelloWorld"`，`s[-1]` 的结果是（　）。**
A. "H"
B. "d"
C. "l"
D. "D"

**11. 表达式 `"ab" + "cd"` 的结果是（　）。**
A. "abcd"
B. "ab cd"
C. "ab"cd"
D. 错误

**12. 表达式 `"ab" * 3` 的结果是（　）。**
A. "ababab"
B. "ab3"
C. "3ab"
D. 错误

**13. 表达式 `"a" in "abc"` 的值是（　）。**
A. 1
B. True
C. False
D. "a"

**14. `"{:.2f}".format(3.14159)` 的结果是（　）。**
A. "3.14"
B. "3.141"
C. "3.15"
D. "3.14159"

**15. `f"{5*2}"` 的结果是（　）。**
A. "5*2"
B. "10"
C. 10
D. "52"

**16. `ord("A")` 的值是（　）。**
A. 65
B. 97
C. 41
D. "A"

**17. `len("hello")` 的值是（　）。**
A. 4
B. 5
C. 6
D. "hello"

**18. `"Hello, World".split(",")` 的结果是（　）。**
A. ["Hello", " World"]
B. "Hello World"
C. ["Hello,", "World"]
D. ("Hello", " World")

**19. `",".join(["a", "b", "c"])` 的结果是（　）。**
A. "abc"
B. "a,b,c"
C. ["a,b,c"]
D. "a b c"

**20. 表达式 `True + True` 的值是（　）。**
A. True
B. 2
C. 1
D. 错误

**21. 表达式 `3 or 5` 的值是（　）。**
A. True
B. 3
C. 5
D. False

**22. 表达式 `0 and 5` 的值是（　）。**
A. 0
B. 5
C. False
D. True

**23. `bool("")` 的值是（　）。**
A. True
B. False
C. 1
D. 错误

**24. 表达式 `"abc" > "abd"` 的值是（　）。**
A. True
B. False
C. "abc"
D. 错误

**25. `print("{:05d}".format(42))` 的输出是（　）。**
A. "00042"
B. "42"
C. "0000042"
D. "42000"

## 参考答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | B | `//` 整除，7//2 = 3 |
| 2 | C | 整除向下取整，-7//2 = -4 |
| 3 | C | 7 = 3×2 + 1，余数 1 |
| 4 | B | `/` 除法永远返回浮点数，4/2 = 2.0 |
| 5 | B | 幂运算右结合：2**(3**2) = 2**9 = 512 |
| 6 | A | divmod 返回 (商, 余数) |
| 7 | B | 四舍五入保留 2 位小数，round(3.14159,2)=3.14 |
| 8 | B | 按二进制解析 "101" = 1×4+0×2+1 = 5 |
| 9 | A | 切片含头不含尾，s[0:5] 取索引 0~4 = "Hello" |
| 10 | B | 负索引从末尾数，-1 是最后一个字符 'd' |
| 11 | A | `+` 连接字符串 |
| 12 | A | `*` 重复字符串 |
| 13 | B | `in` 判断子串，返回 True |
| 14 | A | `:.2f` 保留 2 位小数，3.14159 → 3.14 |
| 15 | B | f-string 中先计算表达式再输出，5*2=10 |
| 16 | A | 'A' 的 Unicode 码是 65，'a' 是 97 |
| 17 | B | len 统计字符个数，hello 是 5 个字符 |
| 18 | A | split 按逗号拆分成列表 |
| 19 | B | join 用逗号把列表元素连接成字符串 |
| 20 | B | 布尔参与运算：True 当作 1，1+1=2 |
| 21 | B | or 短路：左边为真直接取左边值，3 or 5 = 3 |
| 22 | A | and 短路：左边为假直接取左边值，0 and 5 = 0 |
| 23 | B | 空字符串是假值，bool("") = False |
| 24 | B | 字符串按字符依次比较：'a'=='a'，'b'=='b'，'c'<'d'，所以 "abc" < "abd" |
| 25 | A | `:05d` 宽度 5 位，不足补 0，42 → "00042" |
