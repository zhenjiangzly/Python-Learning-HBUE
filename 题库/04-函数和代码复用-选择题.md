## 参考答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | A | f(3) 返回 3×2=6 |
| 2 | B | 无 return 时函数默认返回 None |
| 3 | A | 默认参数：f(5) 中 b=10，5+10=15 |
| 4 | B | 显式传入 b=20，5+20=25 |
| 5 | A | 关键字参数：a=10, b=3，10-3=7 |
| 6 | B | 函数内 x=20 是局部变量，不影响全局 x |
| 7 | B | global 声明后修改的是全局变量，x=20 |
| 8 | B | 斐波那契：fib(1)=1, fib(2)=1, fib(3)=2, fib(4)=3, fib(5)=5 |
| 9 | B | 多返回值打包成元组 |
| 10 | B | 默认参数（可选参数）必须放在非默认参数之后 |
| 11 | A | *args 收集所有参数成元组 (1,2,3)，sum=6 |
| 12 | B | 递归需要结束条件，且每次调用都逼近结束条件 |
| 13 | A | f(4)=4×f(3)=4×3×f(2)=4×3×2×f(1)=24 |
| 14 | A | 关键字参数：x=3, y=2，3×2=6 |
| 15 | D | 全局变量在函数外当然可以访问；函数内不能直接修改全局变量 |
| 16 | B | 函数内 a=2 是局部变量，全局 a 仍为 1 |
| 17 | A | lambda 等价于函数：2+3=5 |
| 18 | B | 单独 return 等价于 return None |
| 19 | A | 闭包：inner 捕获 x=10，g(5)=10+5=15 |
| 20 | B | 函数支持递归调用 |
| 21 | B | 列表是可变对象，函数内修改影响原列表 |
| 22 | B | 字符串不可变，s = s + "!" 只是重新绑定局部变量，外部 x 不变 |
| 23 | A | pow(2,3,5)：2³=8，8%5=3 |
| 24 | A | is_even(4)=True，is_even(5)=False |
| 25 | A | f(3)=3+f(2)=3+2+f(1)=3+2+1+f(0)=3+2+1+0=6 |
