## 参考答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | A | x=5 > 3 成立，输出 A |
| 2 | B | 依次判断：90 不满足 → 80 满足 → 输出"良"并停止判断 |
| 3 | B | range(5) = 0,1,2,3,4，不含 5 |
| 4 | A | range(1,10,2) = 1,3,5,7,9，不含 10 |
| 5 | A | 1+2+3 = 6 |
| 6 | A | i==2 时 break 跳出，只输出 0 1 |
| 7 | B | i==2 时 continue 跳过，输出 0 1 3 4 |
| 8 | B | 循环被 break 打断，else 不执行；B 在循环外一定输出 |
| 9 | A | pass 是空操作不打断循环，循环正常结束执行 else |
| 10 | A | while 条件不变会死循环 |
| 11 | B | 0→2→4→6，n=6 时不满足 n<5，退出，输出 6 |
| 12 | B | 外循环 i=1: j=1,2 → 1 2；i=2: 2 4；i=3: 3 6 |
| 13 | A | 10/0 抛 ZeroDivisionError，except 捕获；else 不执行（有异常）；finally 总执行 |
| 14 | B | 字符串无法转为整数 → ValueError |
| 15 | B | 无异常：else 执行 B，finally 执行 C |
| 16 | B | 59 < 60，条件不成立，取"不及格" |
| 17 | B | i=1 累加 s=1；i=2 continue；i=3 累加 s=4；i=4 continue。s=4 |
| 18 | B | 偶数对 2 取余为 0 |
| 19 | A | i=1:1<20; i=2:4; i=3:9; i=4:16; i=5:25>20 break。break 时 i=5 |
| 20 | B | 字符串遍历：'1'*2='11'，'2'*2='22'，'3'*2='33' |
| 21 | B | 1 < 2，elif 条件成立，输出 B |
| 22 | C | exit 不是循环控制关键字（它是退出程序的函数） |
| 23 | B | x 从 3 递减，先减再输出：2 1 0 |
| 24 | B | range(1,5) = 1,2,3,4，拼接输出 1234 |
| 25 | C | else 块在**没有**异常时执行 |
