# 编程题 · 进阶篇（20 题）

> 对应考试"综合编程题"难度（10 分大题），考察组合数据类型、文件、递归、计算生态的综合运用。
> 建议完成基础篇后再挑战本部分。

---

**1. 素数对**
输出 2~100 之间的所有孪生素数对（差为 2 的素数对，如 (3,5)、(5,7)、(11,13)）。

**2. 完数**
完数指恰好等于其真因子之和的数（如 6 = 1+2+3）。输出 1000 以内的所有完数。

**3. 字符串加密（凯撒密码）**
输入一段英文小写字符串和偏移量 k，将每个字母向后移动 k 位（z 之后回到 a），非字母不变，输出密文。

**4. 约瑟夫环**
n 个人围成一圈报数，报到 m 的人出列。输入 n、m，输出出列顺序。

**5. 汉诺塔**
输入盘子数 n，输出把 n 个盘子从 A 移到 C（借助 B）的每一步移动。

**6. 递归求数字各位之和**
输入一个正整数，用递归函数计算其各位数字之和。例如 12345 → 15。

**7. 列表去重保持顺序**
输入一串数字，去除重复元素并保持第一次出现的顺序，输出结果列表。

**8. 两个列表的公共元素**
输入两个数字列表，输出它们的公共元素（不重复、按原顺序）。

**9. 字典词频 TOP N**
输入一段英文，输出出现次数最多的前 3 个单词及其次数。

**10. 中文词频统计**
用 jieba 对一段中文文本分词，统计词频并输出前 5 个（排除长度 1 的词）。

**11. 学生成绩单（文件）**
`students.csv` 每行 `姓名,语文,数学,英语`（首行为表头）。读取后计算每个人的总分和平均分（保留1位小数），输出总分第一名的姓名和总分。

**12. 文件字符统计**
读取文本文件 `article.txt`，统计并输出：字符总数（不含换行）、单词数、行数。

**13. CSV 转置**
读取 `matrix.csv`（每行逗号分隔的数字，行数列数相同），输出其转置矩阵。

**14. 数据清洗**
`data.txt` 每行一个数字（可能含空白行和非数字行），读取时跳过非法行，输出有效数字的个数、总和、平均值（保留2位小数）。

**15. 随机点名系统**
班级名单存于 `names.txt`（每行一个姓名）。随机抽取 3 名不重复的同学作为上台名单，输出结果。

**16. 简易计算器**
输入形如 `3+5`、`10-2`、`6*7`、`8/4` 的算式（操作符 + - * /），输出结果。注意除数为 0 时提示"除数不能为0"。

**17. 股票收益计算**
输入买入价格和卖出价格（浮点数，用空格分隔），计算收益率百分比（保留 2 位小数）。若为负数输出"亏损"提示。

**18. 回文检测进阶**
输入一个字符串，忽略其中的空格和标点符号（只保留字母数字）后判断是否为回文。

**19. 十进制转二进制**
输入一个十进制整数，不用 bin() 函数，用除 2 取余法输出其二进制表示。

**20. 综合：学生信息管理系统**
用字典列表存储学生信息（姓名、学号、三门课成绩），实现：添加、按学号查找、输出平均分最高的学生、按平均分降序输出全部（模拟菜单）。

## 参考答案

### 1. 素数对

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

primes = [n for n in range(2, 101) if is_prime(n)]
for i in range(len(primes) - 1):
    if primes[i + 1] - primes[i] == 2:
        print(primes[i], primes[i + 1])
```

### 2. 完数

```python
for n in range(2, 1001):
    s = 1
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            s += i
            if i != n // i:
                s += n // i
    if s == n:
        print(n)      # 6 28 496
```

### 3. 凯撒密码

```python
s = input("请输入小写字母字符串：")
k = int(input("请输入偏移量："))
result = ""
for ch in s:
    if ch.isalpha():
        result += chr((ord(ch) - ord('a') + k) % 26 + ord('a'))
    else:
        result += ch
print(result)
```

### 4. 约瑟夫环

```python
n = int(input("人数n："))
m = int(input("报数m："))
people = list(range(1, n + 1))
index = 0
while people:
    index = (index + m - 1) % len(people)
```

### 5. 汉诺塔

```python
def hanoi(n, a, b, c):
    if n == 1:
        print(f"{a} -> {c}")
    else:
        hanoi(n - 1, a, c, b)
        print(f"{a} -> {c}")
        hanoi(n - 1, b, a, c)

n = int(input("请输入盘子数："))
hanoi(n, "A", "B", "C")
```

### 6. 递归求数字各位之和

```python
def digit_sum(n):
    if n == 0:
        return 0
    return n % 10 + digit_sum(n // 10)

n = int(input("请输入正整数："))
print(digit_sum(n))
```

```python
if n == 0:
    print(0)

    bits = []

        bits.append(str(n % 2))
```

### 20. 学生信息管理系统

```python
students = []

def add_student():
    name = input("姓名：")
    sid = input("学号：")
    scores = [float(input(f"成绩{i+1}：")) for i in range(3)]
    students.append({"name": name, "sid": sid, "scores": scores})

def find_student():
    sid = input("请输入学号：")
    for s in students:
        if s["sid"] == sid:
            print(s["name"], sum(s["scores"]) / 3)
            return
    print("未找到")

def best_student():
    if not students:
        print("暂无学生")
        return
    best = max(students, key=lambda s: sum(s["scores"]) / 3)
    print(best["name"], sum(best["scores"]) / 3)

def show_all():
    ranked = sorted(students, key=lambda s: sum(s["scores"]) / 3, reverse=True)
    for s in ranked:
        print(s["name"], sum(s["scores"]) / 3)

while True:
    print("\n1.添加 2.按学号查找 3.最高平均分 4.全部按平均分排序 5.退出")
    choice = input("请选择：")
    if choice == "1":
        add_student()
    elif choice == "2":
        find_student()
    elif choice == "3":
        best_student()
    elif choice == "4":
        show_all()
    elif choice == "5":
        break
```
