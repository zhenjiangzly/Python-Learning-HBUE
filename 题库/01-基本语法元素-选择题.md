## 参考答案与解析

| 题号 | 答案 | 解析 |
|------|------|------|
| 1 | C | `class` 是保留字；`print`、`input`、`type` 是内置函数，不是保留字 |
| 2 | B | 标识符由字母、数字、下划线组成，不能以数字开头，不能含连字符，不能是保留字 |
| 3 | A | 缩进表示代码块的层级，同一层必须一致，否则报 IndentationError |
| 4 | B | `eval()` 计算字符串中的表达式，`3 + 4` 结果是整数 7 |
| 5 | B | `a, b = b, a` 是同步赋值，先计算右边的 (b,a)=(2,1)，再赋值，实现交换 |
| 6 | A | `end=""` 表示末尾不追加换行符，输出不换行 |
| 7 | D | Python 是动态类型语言，变量不需要显式声明类型 |
| 8 | B | `sep="-"` 设置分隔符为 `-` |
| 9 | B | `#` 后的内容是注释，不会执行；注释不影响运行速度 |
| 10 | C | `int("3.5")` 无法转换，抛出 ValueError。先 float() 再 int() 才行 |
| 11 | B | 字符串乘整数是重复字符串，"x"*3 = "xxx"；"x" 不是变量 x |
| 12 | B | a=b 后 a=2，b=a 后 b=2，输出 2 2 |
| 13 | C | 变量名不能以数字开头 |
| 14 | A | `print("A")` 缩进属于 if 块；`print("B")` 无缩进，与 if 并列，一定会执行 |
| 15 | B | input() 的返回值永远是字符串，需要数值必须转换 |
| 16 | B | sep="" 去掉分隔符（345），end="!" 末尾输出感叹号 |
| 17 | C | Python 没有 char 类型，字符用长度为 1 的字符串表示 |
| 18 | A | `type()` 返回类型对象，显示为 `<class 'int'>` |
| 19 | B | `def` 用于定义函数；`import` 导入模块；`with` 上下文管理 |
| 20 | C | 标识符不能以数字开头 |
