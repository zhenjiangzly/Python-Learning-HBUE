# 编程题 · 基础篇（20 题）

> 对应考试"基本编程题"难度。建议：先独立思考并**手写代码**，运行通过后再看答案。
> 参考答案与完整代码在每题答案区，也可以在 [源代码/经典算法](/源代码/经典算法) 中找到相关实现。

---

**1. 温度转换**
输入一个摄氏温度 c，输出对应的华氏温度 f（保留 1 位小数）。公式：f = c × 9/5 + 32。

**2. 数字求和**
输入一个整数 n，计算并输出 1 到 n 的所有整数之和。

**3. 偶数求和**
输入两个整数 a 和 b（a < b），计算 a 到 b 之间所有偶数的和。

**4. 阶乘计算**
输入一个整数 n，输出 n!（n 的阶乘）。例如 5! = 5×4×3×2×1 = 120。

**5. 判断素数**
输入一个大于 1 的整数，判断它是否为素数，输出"是素数"或"不是素数"。

**6. 水仙花数**
水仙花数是三位数，其各位数字的立方和等于它本身（如 153 = 1³+5³+3³）。输出所有水仙花数。

**7. 斐波那契数列**
输出斐波那契数列前 20 项（每项是前两项之和：1, 1, 2, 3, 5, 8...）。

**8. 字符串反转**
输入一个字符串，输出它的逆序字符串。

**9. 字符统计**
输入一个字符串，统计其中英文字母的个数和数字的个数。

**10. 最大公约数**
输入两个正整数，用辗转相除法求它们的最大公约数（GCD）。

**11. 最小公倍数**
输入两个正整数，输出它们的最小公倍数（LCM）。

**12. 九九乘法表**
输出 9×9 乘法表（每行格式如 `1x1=1`）。

**13. 图形打印**
输入行数 n，用 `*` 打印 n 行直角三角形，第 i 行有 i 个 `*`。

**14. 猜数字游戏**
程序随机生成 1~100 的整数，用户不断输入猜测，提示"大了/小了"，猜中输出次数并结束。

**15. 列表统计**
输入 10 个整数，存入列表，输出最大值、最小值和平均值（平均值保留 2 位小数）。

**16. 列表反转**
输入一串用空格分隔的数字，存入列表后原地反转输出（不能用切片 [::-1]）。

**17. 字典统计**
输入一个字符串，统计每个字符出现的次数，按"字符:次数"逐行输出。

**18. 单词计数**
输入一段英文（单词用空格分隔），输出单词个数和每个单词出现的次数。

**19. 文件平均分**
`scores.txt` 文件中每行一个整数成绩，读取后计算并输出平均分（保留 1 位小数）和最高分。

**20. CSV 成绩单**
`grades.csv` 每行是 `姓名,语文,数学`（首行为表头），读取后输出每人的总分，按总分从高到低排序。

## 参考答案

### 1. 温度转换

```python
c = float(input("请输入摄氏温度："))
f = c * 9 / 5 + 32
print(f"华氏温度：{f:.1f}")
```

### 2. 数字求和

```python
n = int(input("请输入n："))
total = 0
for i in range(1, n + 1):
    total += i
print(total)
```

### 3. 偶数求和

```python
a = int(input("请输入a："))
b = int(input("请输入b："))
total = 0
for i in range(a, b + 1):
    if i % 2 == 0:
        total += i
print(total)
```

### 4. 阶乘计算

```python
n = int(input("请输入n："))
result = 1
for i in range(2, n + 1):
    result *= i
print(result)
```

### 5. 判断素数

```python
n = int(input("请输入一个大于1的整数："))
is_prime = True
for i in range(2, int(n ** 0.5) + 1):
    if n % i == 0:
        is_prime = False
        break
if is_prime:
    print("是素数")
else:
    print("不是素数")
```

### 6. 水仙花数

```python
for n in range(100, 1000):
    a = n // 100          # 百位
    b = n // 10 % 10      # 十位
    c = n % 10            # 个位
    if a ** 3 + b ** 3 + c ** 3 == n:
        print(n)          # 153 370 371 407
```

### 7. 斐波那契数列

```python
    a, b = b, a + b
```

### 8. 字符串反转

### 9. 字符统计

```python
s = input("请输入字符串：")
letters = 0
digits = 0
for ch in s:
    if ch.isalpha():
        letters += 1
    elif ch.isdigit():
        digits += 1
print(f"字母：{letters} 个，数字：{digits} 个")
```

### 10. 最大公约数（辗转相除法）

```python
a = int(input("请输入a："))
b = int(input("请输入b："))
x, y = a, b
while y != 0:
    x, y = y, x % y
print(f"{a} 和 {b} 的最大公约数是：{x}")
```

### 11. 最小公倍数

```python
a = int(input("请输入a："))
b = int(input("请输入b："))
x, y = a, b
while y != 0:
    x, y = y, x % y
lcm = a * b // x          # 两数之积 ÷ 最大公约数
print(f"最小公倍数是：{lcm}")
```

### 12. 九九乘法表

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}x{i}={i*j}", end="\t")
    print()
```

### 13. 图形打印

```python
n = int(input("请输入行数："))
for i in range(1, n + 1):

```

### 14. 猜数字游戏

```python
import random

secret = random.randint(1, 100)
count = 0
while True:
    guess = int(input("猜一个1-100的数："))
    count += 1
    if guess > secret:
        print("大了")
    elif guess < secret:
        print("小了")
    else:
        print(f"猜中了！用了 {count} 次")
        break
```

### 15. 列表统计

```python
nums = []
for i in range(10):
    nums.append(int(input("请输入数字：")))
print(f"最大值：{max(nums)}")
print(f"最小值：{min(nums)}")
print(f"平均值：{sum(nums) / len(nums):.2f}")
```

### 16. 列表反转

```python
nums = [int(x) for x in input("请输入数字（空格分隔）：").split()]
for i in range(len(nums) // 2):
    nums[i], nums[len(nums) - 1 - i] = nums[len(nums) - 1 - i], nums[i]
print(nums)
```

### 17. 字典统计

```python
s = input("请输入字符串：")
counts = {}
for ch in s:
    counts[ch] = counts.get(ch, 0) + 1
for ch, n in counts.items():
    print(f"{ch}:{n}")
```

### 18. 单词计数

```python
text = input("请输入英文句子：")
words = text.split()
print(f"单词总数：{len(words)}")
counts = {}
for w in words:
    counts[w] = counts.get(w, 0) + 1
for w, n in counts.items():
    print(f"{w}: {n}")
```

### 19. 文件平均分

```python
with open("scores.txt", "r", encoding="utf-8") as f:
    scores = [int(line.strip()) for line in f]
print(f"平均分：{sum(scores) / len(scores):.1f}")
print(f"最高分：{max(scores)}")
```

### 20. CSV 成绩单

```python
students = []
with open("grades.csv", "r", encoding="utf-8") as f:
    next(f)                     # 跳过表头
    for line in f:
        name, chinese, math = line.strip().split(",")
        total = int(chinese) + int(math)
        students.append((name, total))

students.sort(key=lambda x: x[1], reverse=True)
for name, total in students:
    print(f"{name}: {total}")
```
