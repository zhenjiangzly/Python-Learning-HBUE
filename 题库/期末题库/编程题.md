## 7-1 多分支选择结构-输出成绩等级

输入某同学的高等数学课程成绩，输出得分及成绩等级。成绩大于等于 90 分显示"等级优秀"，小于 90 分大于等于 80 分显示"等级良好"，小于 80 分大于等于 70 分显示"等级中等"，小于 70 分大于等于 60 分显示"等级及格"，小于 60 分显示"等级不及格"。

**输入格式**：在一行中输入一个 [0,100] 之间的整数。

**输出格式**：参见输出样例。

**输入样例 1**：
```
95
```
**输出样例 1**：
```
高数成绩95分，等级优秀
```
**输入样例 2**：
```
50
```
**输出样例 2**：
```
高数成绩50分，等级不及格
```

**参考答案**：
```python
score = int(input())
if score >= 90:
    rank = "等级优秀"
elif score >= 80:
    rank = "等级良好"
elif score >= 70:
    rank = "等级中等"
elif score >= 60:
    rank = "等级及格"
else:
    rank = "等级不及格"
print(f"高数成绩{score}分，{rank}")
```

## 7-2 多分支选择结构-员工工资计算

设员工工号为 id，员工工作时数为 hours，员工应发工资为 income：
1. 正常情况，按工作时数，每小时 84 元计发；
2. 工作时数 hours 超过 120 小时者，超过部分加发 15%；
3. 工作时数 hours 少于 60 小时者，扣发 700 元。

**输入格式**：第一行输入员工工号（字符串），第二行输入员工工作时长（浮点数）。

**输出格式**：在一行中输出员工的工号和应发工资数。

**输入样例**：
```
20251103
123
```
**输出样例**：
```
员工工号为20251103，应发工资为10369.8元。
```

**参考答案**：
```python
emp_id = input()
hours = float(input())
if hours > 120:
    income = 120 * 84 + (hours - 120) * 84 * 1.15
elif hours < 60:
    income = hours * 84 - 700
else:
    income = hours * 84
print(f"员工工号为{emp_id}，应发工资为{income}元。")
```

## 7-3 多分支选择结构-四则运算

输入操作数 a 和 b，输入运算符 c（限 "+"、"-"、"*"、"/"），输出 a 和 b 执行运算 c 后的结果。

**输入格式**：第一行输入操作数 a（浮点数），第二行输入操作数 b（浮点数），第三行输入运算符 c（字符串）。

**输出格式**：在一行中输出对 a 和 b 执行运算 c 后的结果，结果保留两位小数。

**输入样例 1**：
```
2.8
3.6
+
```
**输出样例 1**：
```
2.8+3.6=6.40
```
**输入样例 2**：
```
3.4
0
/
```
**输出样例 2**：
```
除数不能为0
```
**输入样例 3**：
```
3.4
2.7
/
```
**输出样例 3**：
```
3.4/2.7=1.26
```
**输入样例 4**：
```
3.4
2.7
%
```
**输出样例 4**：
```
输入错误
```

**参考答案**：
```python
a = float(input())
b = float(input())
c = input()
if c == "+":
    result = a + b
elif c == "-":
    result = a - b
elif c == "*":
    result = a * b
elif c == "/":
    if b == 0:
        print("除数不能为0")
        exit()
    result = a / b
else:
    print("输入错误")
    exit()
print(f"{a:g}{c}{b:g}={result:.2f}")
```

## 7-4 多分支选择结构-经济发展预警

一般来说，经济总量用 GDP 衡量。假设，当年 GDP 增速低于去年同期 GDP 增速的 70% 或高于 200%，则认为经济发展需要预警。

**输入格式**：第一行输入去年同期 GDP 增速（浮点数），第二行输入当前 GDP 增速（浮点数）。

**输出格式**（注意标点符号是中文格式）：
- `GDP增速不足，经济过冷！`
- `GDP增速过速，经济过热！`
- `GDP增速平稳，达到预期！`

**输入样例**：
```
5.5
14
```
**输出样例**：
```
GDP增速过速，经济过热！
```

**参考答案**：
```python
last = float(input())
cur = float(input())
if cur < last * 0.7:
    print("GDP增速不足，经济过冷！")
elif cur > last * 2:
    print("GDP增速过速，经济过热！")
else:
    print("GDP增速平稳，达到预期！")
```

## 7-5 循环结构-统计大小写英文字母的个数

统计一个英文句子中大写字母和小写字母的个数。

**输入格式**：在一行中输入一个英文句子。

**输出格式**：输出该英文句子中大写字母和小写字母的个数。

**输入样例 1**：
```
Hello World!
```
**输出样例 1**：
```
句子中的大写字母有2个。
句子中的小写字母有8个。
```
**输入样例 2**：（空行）
**输出样例 2**：
```
句子中的大写字母有0个。
句子中的小写字母有0个。
```

**参考答案**：
```python
s = input()
upper = sum(1 for ch in s if ch.isupper())
lower = sum(1 for ch in s if ch.islower())
print(f"句子中的大写字母有{upper}个。")
print(f"句子中的小写字母有{lower}个。")
```

## 7-7 循环结构-求特殊三位数

**输出格式**：每两个数之间以一个空格间隔，每 5 个数一行，每行末尾有一个空格。

**输入样例**：
```
999
```
**输出样例**：
```
132 224 315 453 535
561 635 661 753 805
815
```

**参考答案**：
```python
n = int(input())
count = 0
line = ""
for x in range(100, n + 1):
    a = x // 100
    b = x // 10 % 10
    c = x % 10
    if x // 9 == a * a + b * b + c * c:
        line += f"{x} "
        count += 1
        if count % 5 == 0:
            print(line)
            line = ""
if line:
    print(line)
```

## 7-8 循环结构-求数列和

有数列 2/1, 3/2, 5/3, 8/5, 13/8, ……（分子分母均为斐波那契数，分子领先一项），输入一个正整数 n（1 ≤ n ≤ 50），求该数列前 n 项之和（结果保留两位小数）。

**输入样例**：
```
20
```
**输出样例**：
```
前20项之和为32.66
```

**参考答案**：
```python
n = int(input())
a, b = 1, 2
total = 0.0
for _ in range(n):
    total += b / a
    a, b = b, a + b
print(f"前{n}项之和为{total:.2f}")
```

> 📝 注：原始题面中数列写作 1/2, 2/3, 3/5...，但按输出样例 32.66 验证，应为斐波那契相邻项比值 2/1, 3/2, 5/3...（题面复制可能有误，以样例为准）。

## 7-9 组合数据类型-求最长字符串的长度

输入一个整数 n（n > 0），再输入 n 个字符串，存放在一个列表中，输出其中最长的字符串的长度。

**输入样例 1**：
```
3
a
abc
df
```
**输出样例 1**：
```
最长的字符串的长度为3。
```

**参考答案**：
```python
n = int(input())
strings = [input() for _ in range(n)]
print(f"最长的字符串的长度为{max(len(s) for s in strings)}。")
```

## 7-10 组合数据类型-列表插入

给定一个按降序排列的列表 numlist=[100,88,81,80,75,71,69,65,60,59,30]，输入一个数，将其插入到合适的位置，保持列表降序，然后重新输出。

**输出格式**：输出列表中的元素，每两个元素间以空格间隔，结尾有一个空格。

**输入样例**：
```
70
```
**输出样例**：
```
100 88 81 80 75 71 70 69 65 60 59 30
```

**参考答案**：
```python
numlist = [100, 88, 81, 80, 75, 71, 69, 65, 60, 59, 30]
x = int(input())
numlist.append(x)
numlist.sort(reverse=True)
print(" ".join(map(str, numlist)) + " ")
```

## 7-11 组合数据类型-列表与字符串

输入 5 个不同的字符串，存储到列表中，将所有字符串中的英文字母转换为大写字母后存储到新列表中，并将新列表按字符 ASCII 编码的大小排成升序，输出排序后的结果。

**输入样例**：
```
As
ghJ
TYrt
bb
DC
```
**输出样例**：
```
新列表为['AS', 'GHJ', 'TYRT', 'BB', 'DC']
排序后的列表为['AS', 'BB', 'DC', 'GHJ', 'TYRT']
```

**参考答案**：
```python
strings = [input() for _ in range(5)]
new_list = [s.upper() for s in strings]
print(f"新列表为{new_list}")
new_list.sort()
print(f"排序后的列表为{new_list}")
```

## 7-12 组合数据类型-字典

给定字典 phone_book = {"张小红":"15013767368", "李四":"15262356789", "胡旭":"15897653123", "王梅":"156325879411", "孙兴":"15248936126"}，输入一个联系人的姓名，如果不存在输出"查无此人"，存在则输出其手机号。

**输入样例 1**：
```
李四
```
**输出样例 1**：
```
李四的电话是15262356789
```
**输入样例 2**：
```
张三
```
**输出样例 2**：
```
查无此人
```

**参考答案**：
```python
phone_book = {"张小红": "15013767368", "李四": "15262356789",
              "胡旭": "15897653123", "王梅": "156325879411",
              "孙兴": "15248936126"}
name = input()
if name in phone_book:
    print(f"{name}的电话是{phone_book[name]}")
else:
    print("查无此人")
```
