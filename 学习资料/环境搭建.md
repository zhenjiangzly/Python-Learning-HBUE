# 🔧 环境搭建指南

> 替代原仓库中的安装包，所有资源均提供官方/镜像下载链接，无需在仓库中存放大型文件。

## 1. 安装 Python

### 官方下载（推荐）

- 官网：https://www.python.org/downloads/
- 直接下载 Windows 安装包（64 位）：https://www.python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe

> 📌 **版本选择建议**：考试环境是 Python 3.5.3 ~ 3.9.10。
> 推荐安装 **3.8.x**（对 f-string 等新特性支持完整，又与考试环境兼容）。

### 国内镜像（下载速度快）

- 华为云：https://mirrors.huaweicloud.com/python/3.8.10/
- 淘宝 npm（曾镜像 Python）：https://registry.npmmirror.com/binary.html?path=python/

### 安装要点

1. 勾选 **"Add Python to PATH"**（关键！否则命令行找不到 python）
2. 默认安装位置即可：`C:\Users\你的用户名\AppData\Local\Programs\Python\Python38`
3. 验证：打开命令行输入 `python --version`，看到 `Python 3.8.x` 即成功

## 2. 使用 IDLE（考试环境）

安装完成后，开始菜单中找到 **IDLE (Python 3.8 64-bit)**。

### IDLE 常用操作

| 操作 | 说明 |
|------|------|
| 新建文件 | `File → New File`（或 Ctrl+N） |
| 运行程序 | `Run → Run Module`（或 **F5**） |
| 交互模式 | 直接输入代码回车执行（适合测试小片段） |
| 缩进 | Tab 自动缩进，注意代码块层级 |
| 查看帮助 | `Help → Python Docs` |

> ⚠️ **务必用 IDLE 练习**：考场就是 IDLE，提前熟悉能节省宝贵时间。

## 3. pip 换源（加速第三方库安装）

pip 默认从国外 PyPI 下载，速度慢。配置国内镜像：

### 临时指定源

```bash
pip install jieba -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 永久换源（推荐）

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

常用镜像（任选其一）：

| 镜像 | 地址 |
|------|------|
| 清华 | https://pypi.tuna.tsinghua.edu.cn/simple |
| 阿里云 | https://mirrors.aliyun.com/pypi/simple |
| 华为云 | https://mirrors.huaweicloud.com/repository/pypi/simple |
| 腾讯云 | https://mirrors.cloud.tencent.com/pypi/simple |

## 4. 常用命令速查

```bash
python --version                 # 查看版本
pip --version                    # 查看 pip 版本
pip list                         # 已安装的库
pip install 库名                 # 安装
pip install 库名 -i 镜像地址      # 用镜像安装
pip uninstall 库名               # 卸载
pip show 库名                    # 查看库信息
```

## 5. 可选：VSCode 配置（非考试必需）

1. 下载 VSCode：https://code.visualstudio.com/
2. 安装扩展：**Python**（微软官方）
3. 打开 `.py` 文件即可自动识别，Ctrl+F5 运行
4. 选择解释器：Ctrl+Shift+P → "Python: Select Interpreter" → 选 3.8

> ⚠️ 日常可以用 VSCode 提高效率，但**考前最后一周务必回归 IDLE**。

## 6. 常见问题

| 问题 | 解决 |
|------|------|
| `python` 不是内部或外部命令 | 安装时没勾 PATH，重装或手动添加环境变量 |
| 安装库报错网络超时 | 用 `-i` 指定国内镜像 |
| 中文乱码 | 打开文件加 `encoding="utf-8"` |
| pip 不是内部命令 | 重装 Python 并勾选 PATH |
| 无法打开 exe 程序 | 用 PyInstaller 打包时加 `-F` 生成单文件 |
